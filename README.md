## 🌍 Overview
**GoalForecast** is a web application designed to predict **Premier League**, **La Liga**, and **NFL** game outcomes using a combination of **statistical models** and **search algorithms** like *Game Tree Search* and *Heuristic Search*.  

The platform uses:
- 🖥 **React.js** for the Frontend  
- 🧩 **Python (Flask)** for the Backend  
- 📊 Custom Variables like Team Strength, Match Context, and Past Performance  

---

## 🧩 Features
✅ Predict match outcomes  
✅ Display recent team performance stats  
✅ Adjustable heuristic factors for predictions  
✅ User-friendly web interface
